# Hey, I'm Gunter 👋

I like building teams, platforms, and lately, workflows where AI agents do the boilerplate typing and I get to do the thinking.

For the last four years I was the first technical hire at a fintech trading platform, which meant I got to (had to?) build everything from scratch: the team, the culture, the infrastructure. We took uptime from "mostly fine" (~95%) to 99.9%+ and kept it there. Still a bit proud of that one.

Things this taught me that I didn't see coming:

- **Contractors build systems; teams build culture.** Our biggest reliability win wasn't technical, it was moving ownership to people who actually cared whether the platform stayed up at 3am.
- **AI tools make engineers faster and quietly worse (unless you coach the mindset first.)** We rolled out AI coding tools and watched output rise while quality silently dipped. Mindset first, access second.
- **Your cloud bill can take down production.** Ask me about the three hours I'd most like back.

These days I'm deep into agentic development and my team ran Claude-based agents as standard practice. I think it's the biggest shift in how software gets built since CI/CD.

Before all this: a PhD in biomedical engineering, a startup CTO chapter, and ML on energy data.
